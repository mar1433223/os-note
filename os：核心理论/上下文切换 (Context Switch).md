
# 第六章 机制： 受限直接执行

## 问题2：在进程直接切换

- **重新获得CPU控制权**:
  - **协作式**：通过等待系统调用或者进程有非法操作会把控制权给OS，但也有问题如果一直循环不进行上面的操作，控制权就给不到OS
  - **抢占式**：通过时钟中断让操作系统重新获得控制权
- **保存和恢复上下文**：
  - 在操作系统获得控制权之后，通过系统调度来决定是否切换进程
  - 用户态->内核态(陷阱):寄存器、PC压入**内核栈**
  - 上下文切换：内核栈保存用户现场，寄存器被存入PCB中

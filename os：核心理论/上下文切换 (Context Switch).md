
# 第六章 机制： 受限直接执行

## 问题2：在进程之间切换

> [!INFO] 核心问题
> OS 怎么把 CPU 从一个进程手里拿回来，再交给另一个进程？

---

## 重新获得 CPU 控制权

- **协作式**：进程通过系统调用、等待 I/O、非法操作等方式把控制权交回 OS。
  问题是：如果进程一直死循环，不主动交出来，OS 就很难拿回控制权。
- **抢占式**：通过**时钟中断**定期打断进程，让 OS 重新获得控制权。

---

## 保存和恢复上下文

OS 获得控制权之后，会通过 [[CPU 调度算法]] 决定是否切换进程。

这里有两层保存：

- **陷阱 / 中断时**：硬件把用户态现场（比如 PC、部分寄存器）压到**内核栈**。
- **上下文切换时**：OS 把旧进程需要恢复的寄存器状态保存到 **PCB**，再从新进程 PCB 中恢复状态。

所以上下文切换的本质就是：
把旧进程“暂停时的样子”存起来，再把新进程“上次暂停的样子”恢复出来。

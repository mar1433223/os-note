### 内存虚拟化

核心问题：OS 怎么让每个进程都拥有一块“看起来连续、互不干扰”的内存？

- [地址空间 (Address Space)](<./os：核心理论/地址空间 (Address Space).md>)
- [地址转换机制](<./os：核心理论/地址转换机制.md>)
- [分页机制 (Paging)](<./os：核心理论/分页机制 (Paging).md>)
- [TLB (翻译后备缓冲器)](<./os：核心理论/TLB (翻译后备缓冲器).md>)
- [多级页表](<./os：核心理论/多级页表.md>)

这条线目前最重要的理解是：

```text
Base & Bounds 太粗 -> 分段解决内部空洞 -> 分段有外部碎片
-> 分页解决外部碎片 -> 分页带来慢和页表大
-> TLB 解决慢 -> 多级页表解决页表大
```

## 笔记风格

这些笔记主要服务于理解，不追求百科式完整。

- 标题尽量清晰。
- 常用结构：**核心问题 / 为什么需要 / 核心思想 / 流程 / 缺陷 / 引出下一章**。
- 重点概念会加粗。
- 保留 Obsidian 的 `[[双链]]`、callout 和图片嵌入。
- 语言尽量直观，比如“程序是尸体，进程是活的”这种说法会保留。
